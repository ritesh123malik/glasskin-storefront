# Production Readiness Plan

This repository follows the 15-phase production-readiness program supplied by
the project owner on 2026-08-27. Phases must be completed in dependency order:

0. Agent ground rules
1. Cart persistence and production fallback removal
2. Commerce data model
3. Stripe webhook, order lifecycle, transactional email
4. Customer account and admin order operations
5. Server-side promotions
6. Checkout and platform security
7. Payment methods, GST, invoices, and COD
8. India legal and product compliance
9. Catalog media, reviews, and SEO
10. Customer experience expansion
11. Marketing and retention
12. Observability and reliability
13. Automated tests and CI
14. Accessibility, SEO infrastructure, and operations documentation

See `CLAUDE.md` for non-negotiable security and verification requirements.
Record implementation decisions there as phases complete.
